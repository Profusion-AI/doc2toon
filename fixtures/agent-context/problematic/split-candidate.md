## Conversion, Release, Privacy, And UI Workflow

When reviewing conversion behavior, inspect parser output, canonical JSON, TOON encoding, decoded JSON, and measured savings.

When preparing release notes, summarize changed behavior, list validation commands, avoid broad savings claims, and keep private operating details out of public docs.

When reviewing privacy posture, confirm that source document bodies stay local, no telemetry is added, no hosted processing is introduced, and no secrets are committed.

When drafting UI copy, describe measured context density, show advisory warnings, avoid magical summarizer language, and make clear that humans decide what nuance matters.
