# Code of Conduct

## Standard

This project expects direct, respectful, practical collaboration.

Be clear about behavior, evidence, and tradeoffs. Critique code and claims, not people. Assume maintainers may ask for measurements, fixtures, or narrower changes before accepting a pull request.

## Unacceptable behavior

Unacceptable behavior includes:

- harassment, threats, or personal attacks
- discriminatory language or conduct
- publishing private information without permission
- sustained off-topic disruption
- knowingly misleading claims about project behavior, affiliation, security, or compression results

## Enforcement

Maintainers may remove comments, close issues, reject contributions, or block participants when behavior makes the project less safe or less useful.

If you need to report conduct privately, contact the maintainer through a private GitHub channel if available.
